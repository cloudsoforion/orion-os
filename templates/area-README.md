## Backlog

Not-yet-started improvements live in [[01-Areas/<Area-Name>/backlog|backlog]] as `paused`
(committed but set down) or `someday` (an idea). **They graduate to `02-Projects/` only when they go
`active`** — that graduation is the one moment a doc moves, and it moves in Obsidian, never `mv`.
